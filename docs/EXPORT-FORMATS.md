# Export formats — evidence log

Real-world export shapes the parser must handle, with evidence. Every new
pattern added to the parser needs a fixture (`tests/fixtures/whatsapp/`) and,
where it came from a real device, an entry here. Fixtures are synthetic
(generated by `scripts/generate-fixtures.ts`); this file records the
observed shapes that motivated them.

## iOS exports

- Header: `[DD/MM/YYYY, H:MM:SS<NNBSP>AM] Author: text` — narrow no-break
  space (U+202F) before the meridiem; seconds present. _(observed on iOS 17,
  WhatsApp 2.23.x)_
- A left-to-right mark (U+200E) precedes `<attached: …>` markers, system
  texts written under the group name, and deleted/edited markers.
- System events appear as `[ts] Group Name: ‎<system text>`.
- Dates are DMY in most locales; MDY on en_US devices (second component
  exceeds 12 in evidence).
- Archives contain the chat as `_chat.txt` plus media in folders.

## Android exports

- Header: `DD/MM/YYYY, HH:MM - text` — no seconds by default.
- System events are top-level lines (`X created group "Y"`, `X added Y`,
  `X left`, `X changed the subject from "A: B" to "C"` — note system text
  can contain `": "`, so the system check precedes author splitting).
- Attachments: `FILENAME (file attached)` as the first body line, caption on
  following lines. `X (file attached)` file names follow the
  `IMG-/VID-/PTT-/AUD-/STK-/DOC-` prefix convention.
- Media omitted exports replace each media message with `<Media omitted>`,
  `image omitted`, `video omitted`, `audio omitted`, `sticker omitted`,
  `GIF omitted`, `document omitted`, or `Contact card omitted`.
- Encrypted notice: `…can read or listen to them. Tap to learn more.`
- Phone numbers as authors (`+92 300 1234567`) occur for unsaved contacts.

## Shared shapes

- 2-digit years occur (`17/11/26`) and map to 2000+yy.
- Dot-separated dates (`17.11.26.`) occur in European locales; a trailing
  dot after the year is possible.
- YMD order (`2026-11-17`) is rare but present in some locales.
- Multi-line messages: any line not matching a header grammar is a
  continuation; blank lines inside a message are preserved.
- CRLF line endings and a UTF-8 BOM occur in exports moved through Windows.
- Timestamps can repeat and go backwards (manual clock edits); file order is
  authoritative.
- Author-splitting is at the FIRST `": "`; bodies may contain further
  `": "` (e.g. "meeting at 10:00").

## Known ambiguities

- When every date component is ≤ 12, DMY vs MDY cannot be decided from the
  file; the import UI must ask the user (§12.8) — `dateOrderSource` is
  `default` (no hint) or `locale-hint`.

## Adding evidence

Export from a real device, anonymize with `pnpm anonymize`, and file the
anonymized sample (or its shapes) plus a new fixture variant in this
repository. Update `docs/EXPORT-FORMATS.md` in the same PR.
